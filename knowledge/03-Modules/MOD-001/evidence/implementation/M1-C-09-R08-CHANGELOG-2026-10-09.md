## Behaviour
Entry is derived from `git log --first-parent <from>..<to>`: `Merge pull request #N from …` merge commits
(title = first body line) and squash commits ending `(#N)`. PR titles with conventional type
chore/ci/docs/test/style/build are not changelog-worthy. No worthy PR → no stdout, no file write, exit 0.
Fail closed (exit 1, `DEFECT:` on stderr): bad release id (`train-YYYY.NN`), unresolvable/option-like refs,
from-ref not ancestor of to-ref, empty range, malformed PR merge subject, empty PR title, non-PR merge commit,
duplicate PR number, `--output` already holding the release id.
