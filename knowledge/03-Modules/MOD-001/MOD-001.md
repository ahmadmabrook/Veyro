## Negative check (in the workflow)
With an empty runner home (no pin): `runner.py verify-baseline` must exit 1 with `NOT_PINNED`; `pin-baseline` without `--confirm-index-sha256`, or with a wrong hash, must exit 2 and write no pin. This proves the runner fails closed locally. This negative check does **not** verify the actual source documents against a trusted CI pin; the real mission pin lives outside the repository.

### Run / deploy / rollback (local only; "staging" = local staging profile, NOT cloud staging)
- Tests/lint: `cd backend && python -m pip install -r requirements-dev.txt && python -m ruff check . && python -m mypy && python -m unittest discover -s tests -t . -v`
- Deploy + smoke: `bash infra/scripts/deploy.sh <local|development|staging> <release-tag>` (serves `127.0.0.1:${VEYRO_PORT:-8000}`; fails if smoke does not match exact env and release). Stop: `VEYRO_TARGET=<t> VEYRO_RELEASE=<tag> docker compose -f infra/compose.yaml down`.
- Rollback: redeploy the previous known-good tag with the same `deploy.sh`. Rehearsal: `bash infra/scripts/rollback-rehearsal.sh [target]` (deploys good, deploys a deliberately invalid-config release which must fail smoke, redeploys good).
