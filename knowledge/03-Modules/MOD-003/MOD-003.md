## S1 scope (this slice)
Pure stdlib functions under `backend/app/l10n/`, no state, no API route, no network, no logging, no persistence:

- `conventions.py`: locales exactly `ar`/`en` (anything else raises `ValueError`), direction, bidi `isolate` and `sanitize_untrusted` (rejects untrusted text over 256 characters or containing any Unicode Cc, Zl (U+2028) or Zp (U+2029) code point, with fixed errors; Zl/Zp are paragraph separators that could break the isolated run, so they are refused. It strips, rather than rejects, the bidi embedding/override/isolate controls U+202A-202E and U+2066-2069, which are not Cc. Other format characters such as ZWJ, LRM and RLM pass through), explicit `latn`/`arab` numbering (never derived from locale), integer grouping (floats rejected), money as integer minor units with ISO 4217 codes from the closed table `{JOD: 3, USD: 2}` (ISO code plus amount, no symbols, LTR-isolated inside Arabic), WCAG 2.x contrast with AA text at 4.5:1.
- `messages.py` and `catalog/{en,ar}.json`: `{name}` placeholders, CLDR cardinal plurals (ar zero/one/two/few/many/other, en one/other), ar-to-en fallback flagged `fallback=True`, unknown placeholder is an error, and the R08 `qa_gaps` gate (key parity, placeholder parity, plural completeness).
- `fixture.py`: `render_balance_line` returns `{lang, dir, text}`; manual QA via `python -m app.l10n.fixture`.
- `backend/tests/test_l10n.py`: HP, VAL, NEG, BND, SEC, IDEM, R08 gate and PERF baseline tests; deterministic, no skips.

Exceptions never echo caller-supplied values.

Not built and not claimed: date/time/week-start, tax, name, address, phone formatting; translation workflow, glossary, screenshot review; tenant overrides; regional policy packs; time zones; any UI, screen reader, keyboard, focus, dynamic type, reduced-motion, caption or touch-target behavior; any database, API or event.

## Security baseline (EIP ¶1921), static-only
Itemized, with none proven beyond static code and test evidence:
- Authentication/authorization as applicable: OPEN, no runtime exists.
- Tenant isolation: OPEN, pending MOD-004.
- Input/output data exposure: static only; `sanitize_untrusted` rejects over-length text and Cc, Zl or Zp characters with fixed messages, and strips U+202A-202E and U+2066-2069 bidi controls (ZWJ, LRM and RLM pass through); exceptions carry fixed messages.
- Bounds (`conventions.py`): integers must fit 256 bits (`MAX_INTEGER_BITS`, |value| < 2**256, about 77 decimal digits; also applied to plural counts in `messages.py`); untrusted text is limited to 256 characters (`MAX_UNTRUSTED_TEXT_CHARS`); any placeholder value passed to `translate()` is limited to 512 characters (`MAX_PLACEHOLDER_CHARS`). Over-limit input is rejected, not truncated.
- Secrets/dependency hygiene: static only; stdlib only, no secrets, no new dependency, lockfiles untouched.
- Sensitive logging: static only; no logging module imported (source scan test).
- Privacy classification: OPEN, no data store.
- Abuse-negative scenarios: static only; bidi override injection is neutralized by stripping U+202A-202E and U+2066-2069, while unknown locale/currency and float/bool inputs are rejected.
