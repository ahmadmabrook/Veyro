## Note on F5-005 (the one P1 left genuinely untouched)

session doesn't have access to (a way to observe model substitution from
outside the model's own self-report) or a genuine forced-fallback
mechanism (pinning an agent to a deliberately non-resolvable model alias

rather than silently substituting). Attempting a fake version of this test
would produce exactly the "weak evidence credited as strong" pattern this
whole review exists to catch. Left honestly open, carried forward
alongside the pre-existing Opus-infrastructure-unavailability gap this
project has tracked since Phase 1.
