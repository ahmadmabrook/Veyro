SCALE · 500 TO 100,000
Nothing on this screen enumerates the full set. Filters query server-side, the count states matches against total, selection is bounded to the loaded page with an explicit “select all 18 matching” when a filter is active. There is no state where 4,812 rows render. At 100,000 the only change is that the unfiltered default becomes “recently active” rather than everyone.
STATES · ADM-MEM-05
Empty search names the query and offers to clear filters, never “no data”. Loading is 12 skeleton rows at 34px. Restricted — a receptionist sees the table without the balance column and without Export. Bulk in progress shows per-row outcome, not a modal spinner. Partial failure on a bulk send lists which failed and offers retry on those only.
